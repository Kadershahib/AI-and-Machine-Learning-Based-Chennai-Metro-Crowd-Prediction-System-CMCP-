# Docs folder

Put these here as you produce them:
- report/CMCP_Final_Report.docx — your project report
- ppt/CMCP_Review_Presentation.pptx — review/viva slides
- screenshots/ — real screenshots of the running app for your report

Ask Claude to help draft the report or PPT once your app is running and you have
real screenshots — it can structure the whole report (abstract, literature survey,
methodology, system design, implementation, results, conclusion) around what's
already built here.
